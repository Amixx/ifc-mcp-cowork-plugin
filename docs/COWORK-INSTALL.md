# Add IntelliFence to Cowork from the UI

## Step 1: Open Customize → Browse plugins

![Cowork view with arrow to Customize](./images/add-to-cowork-1.png)

![Customize view with arrow to Browse plugins](./images/add-to-cowork-2.png)

## Step 2: Personal tab → Add marketplace from GitHub

![Personal plugins tab with Add from GitHub highlighted](./images/add-to-cowork-3.png)

## Step 3: Paste the repository URL and sync

Paste the IntelliFence repository URL (`https://github.com/Amixx/ifc-mcp-cowork-plugin`) and click `Sync`.

![GitHub URL pasted into the Add marketplace from GitHub dialog](./images/add-to-cowork-4.png)

## Step 4: Install IntelliFence

![IntelliFence listed with Install button highlighted](./images/add-to-cowork-5.png)

## Step 5: Start a new session

Start a new Cowork session, connect a folder with IFC files, and you're good to go!

![Starting a new session with IntelliFence](./images/add-to-cowork-6.png)
